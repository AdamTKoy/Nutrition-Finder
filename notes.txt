Building an app using Node.js, TypeScript, and Tailwinds CSS

steps:
- create project folder
- update node and nvm:
    nvm install --lts
    nvm use --lts (if it didn't automatically)
- check versions:
    node --version
    nvm --version
- create project framework
    npx create-next-app@latest . --typescript --tailwind --eslint --app --src-dir --import-alias "@/*" --use-npm

To start the server:
    npm run dev
    - this app uses port 3000, so navigate to: localhost:3000

To quit the server: Ctrl-C

Additional installs:
- npm install @vis.gl/react-google-maps

**Testing via browser's developer console**
- had to type "allow pasting" first (for security)
- calls our internal endpoints and doesn't require pasting API keys

> Run this to get first page:

var placesParams = new URLSearchParams({
  chain: "Chipotle",
  lat: "41.8839927",
  lng: "-87.61970559999999",
});

var firstPage = await fetch(
  `/api/restaurants?${placesParams}`,
).then((response) => response.json());

console.log("First page:", firstPage);

> If firstPage.nextPageToken contains a string, you can query for the second page with:

placesParams.set("pageToken", firstPage.nextPageToken);

var secondPage = await fetch(
  `/api/restaurants?${placesParams}`,
).then((response) => response.json());

console.log("Second page:", secondPage);
